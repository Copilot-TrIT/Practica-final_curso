# Practica-final-curso
Ejercicio voluntario final de curso

## Agregar Nueva Funcionalidad al Proyecto MasterNet

Dentro del proyecto trabajado en este curso llamado **MasterNet**, se agregará una nueva funcionalidad para gestionar precios.

### Requerimientos

1. **Crear la funcionalidad para insertar un nuevo precio, usando GitHub Copilot:**

   a. Crear un nuevo archivo llamado `PrecioCreateCommand`.

   b. Crear el componente `Handler`, donde se agregará la lógica necesaria para insertar un nuevo precio.

   c. Crear un nuevo método en el `Controller`, que permita a un cliente enviar un request para la inserción del nuevo precio.

2. **Crear un Unit Test**, para evaluar si la inserción del precio es correcta.

> Puedes utilizar **Visual Studio** o **Visual Studio Code** para desarrollar estas funcionalidades.
